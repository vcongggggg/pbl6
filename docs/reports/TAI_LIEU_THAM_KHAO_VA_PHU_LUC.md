## PHỤ LỤC A: BẢNG TRA CỨU THUẬT NGỮ VÀ TỪ VIẾT TẮT (GLOSSARY & ACRONYMS)

| Từ Viết Tắt | Thuật Ngữ Tiếng Anh Đầy Đủ | Ý Nghĩa & Ứng Dụng Trong Hệ Thống PBL6 |
| :--- | :--- | :--- |
| **API** | Application Programming Interface | Giao diện lập trình ứng dụng (REST, GraphQL, SOAP/XML, JSON-RPC). |
| **BFF** | Backend-For-Frontend | Tầng proxy phía máy chủ Next.js (`/api/gateway/*`) chèn `X-API-Key` an toàn, không lộ secret ra trình duyệt. |
| **BOLA / IDOR** | Broken Object Level Authorization | Lỗ hổng phân quyền mức đối tượng (OWASP API1:2023). |
| **CWE-502** | Deserialization of Untrusted Data | Lỗ hổng thực thi mã khi giải tuần tự hóa dữ liệu Pickle không tin cậy — được triệt tiêu bằng Zero-Pickle UBJSON/NPZ và `weights_only=True`. |
| **DQN** | Deep Q-Network | Mạng nơ-ron học tăng cường sâu có Action Masking (`evasion_agent.pt`) của Red Team. |
| **FPR / TPR** | False Positive Rate / True Positive Rate | Tỷ lệ báo động giả trên mẫu sạch / Tỷ lệ phát hiện chính xác mã độc (Recall). |
| **iForest** | Isolation Forest | Thuật toán học không giám sát phát hiện dị biệt Zero-Day (`iforest_v2.npz`). |
| **MDP** | Markov Decision Process | Quy trình quyết định Markov mô hình hóa chuỗi tấn công né tránh WAF (40-D state, 14 actions). |
| **ReDoS** | Regular Expression Denial of Service | Lỗ hổng quay lui hàm mũ/bậc hai của biểu thức chính quy gây treo CPU. |
| **RPS** | Requests Per Second | Thông lượng yêu cầu xử lý mỗi giây (Blue Team v2.0 đạt `253–340 RPS @ C=50`). |
| **SLA** | Service Level Agreement | Cam kết độ trễ và chất lượng dịch vụ (`AI <= 2.5 ms`, `Full WAF <= 5 ms`, `Throughput >= 150 RPS`). |
| **UBJSON / NPZ** | Universal Binary JSON / NumPy Zip Archive | Hai định dạng lưu trữ mô hình **Zero-Pickle** cho XGBoost v2.0 và Isolation Forest v2.0. |
| **WAF** | Web Application Firewall | Tường lửa ứng dụng web Tầng 7 bảo vệ Web API. |
| **WAL** | Write-Ahead Logging | Chế độ nhật ký đồng thời của SQLite kết hợp `busy_timeout=5000` và Leader-Follower Group Commit. |
| **XAI** | Explainable Artificial Intelligence | Khả năng giải trình quyết định AI qua vector 26-D, luật khớp và bảng trọng số rủi ro trên SOC Dashboard. |
| **XGBoost** | Extreme Gradient Boosting | Mô hình Champion Cost-Sensitive Regularized GBDT v2.0 (`xgb_v2.ubj`). |

## PHỤ LỤC C: ĐẶC TẢ ĐẦY ĐỦ VECTOR 26 ĐẶC TRƯNG THỐNG NHẤT (UNIFIED 26-D FEATURE VECTOR)

Toàn bộ 26 đặc trưng dưới đây khớp 100% với `ml-engine/features/extractor.py`, `xgb_v2_metadata.json`, `iforest_v2_metadata.json` và tab *Payload Evidence Drawer* trên SOC Dashboard:

| STT | Tên Đặc Trưng (`extractor.py`) | Nhóm Đặc Trưng | Ý Nghĩa Phát Hiện Toán Học & An Ninh |
| :---: | :--- | :--- | :--- |
| 1 | `length` | Hình thái nền | Tổng độ dài ký tự bề mặt HTTP payload chuẩn hóa. |
| 2 | `entropy` | Hình thái nền | Độ hỗn loạn Shannon Entropy H(S) (bit); tăng vọt khi bị mã hóa/làm rối. |
| 3 | `count_single_quote` | Hình thái nền | Số dấu nháy đơn `'` — chỉ báo cốt lõi của SQL Injection. |
| 4 | `count_double_quote` | Hình thái nền | Số dấu nháy kép `"` — chỉ báo SQLi/XSS thuộc tính HTML. |
| 5 | `count_less_than` | Hình thái nền | Số dấu `<` — chỉ báo mở thẻ HTML/XML/XSS. |
| 6 | `count_greater_than` | Hình thái nền | Số dấu `>` — chỉ báo đóng thẻ HTML/XML/XSS hoặc chuyển hướng shell. |
| 7 | `count_semicolon` | Hình thái nền | Số dấu `;` — chỉ báo stacked SQL queries hoặc nối lệnh OS shell. |
| 8 | `count_hyphen` | Hình thái nền | Số dấu `-` — chỉ báo chuỗi chú thích SQL `--` và tham số cờ dòng lệnh. |
| 9 | `count_slash` | Hình thái nền | Số dấu `/` — chỉ báo Path Traversal Unix và comment `/**/`. |
| 10 | `count_backslash` | Hình thái nền | Số dấu `\` — chỉ báo Path Traversal Windows và escape sequence. |
| 11 | `count_parenthesis` | Hình thái nền | Số dấu ngoặc đơn `(` và `)` — chỉ báo gọi hàm JS/SQL/subshell. |
| 12 | `special_char_ratio` | Hình thái nền | Tỷ lệ ký tự đặc biệt trên tổng chiều dài chuỗi. |
| 13 | `sql_keyword_count` | Cú pháp OWASP | Tần suất từ khóa SQL nhạy cảm (`SELECT`, `UNION`, `DROP`, `WHERE`...). |
| 14 | `xss_keyword_count` | Cú pháp OWASP | Tần suất từ khóa JavaScript/DOM (`script`, `alert`, `onerror`, `eval`...). |
| 15 | `sqli_regex_matches` | Cú pháp OWASP | Số mẫu biểu thức cú pháp SQLi điển hình khớp (`UNION SELECT`, `OR 1=1`). |
| 16 | `xss_regex_matches` | Cú pháp OWASP | Số mẫu thực thi XSS khớp (`<script>`, `javascript:`, `on*=`). |
| 17 | `path_traversal_matches` | Cú pháp OWASP | Số mẫu duyệt thư mục khớp (`../`, `..\`, `/etc/passwd`, `win.ini`). |
| 18 | `cmd_keyword_count` | Cú pháp OWASP (v2.0) | Tần suất lệnh & trình thông dịch hệ điều hành (`cat`, `whoami`, `bash`, `python3`, `curl`...). |
| 19 | `cmd_regex_matches` | Cú pháp OWASP (v2.0) | Số mẫu nối lệnh shell khớp (`;`, `|`, `&&`, `` `...` ``, `$(...)`, `${IFS}`). |
| 20 | `encoding_layer_depth` | Ngữ cảnh v2.0 | Số vòng giải mã URL/HTML lồng nhau cần thiết để chuỗi hội tụ (bắt double-encoding). |
| 21 | `sql_comment_and_func_score` | Ngữ cảnh v2.0 | Điểm trọng số comment nội tuyến (`/**/`, `/*!50000`) và hàm SQL (`CHAR()`, `SLEEP()`). |
| 22 | `param_value_entropy_ratio` | Ngữ cảnh v2.0 | Tỷ số giữa entropy giá trị tham số và entropy tổng thể — tách payload đột biến cục bộ. |
| 23 | `numeric_anomaly_flag` | Ngữ cảnh v2.0 | Cờ phát hiện chèn toán tử vào tham số vốn chỉ mang giá trị số (`id=1 OR 1=1`). |
| 24 | `natural_text_ratio` | Chống FP v2.0 | Tỷ lệ từ ngữ tự nhiên hợp lệ (giúp giảm mạnh False Positive trên văn bản người dùng sạch). |
| 25 | `safe_structured_ratio` | Chống FP v2.0 | Tỷ lệ cấu trúc JSON/XML khóa–giá trị chuẩn (giúp giảm False Positive trên REST/SOAP hợp lệ). |
| 26 | `protocol_complexity_score` | Ngữ cảnh v2.0 | Độ phức tạp cấu trúc giao thức lồng nhau (GraphQL nesting, SOAP envelope, JSON sâu). |
