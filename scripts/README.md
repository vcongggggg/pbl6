# Development & Automation Scripts

Thư mục `scripts/` chứa các script tiện ích phục vụ phát triển, khởi tạo database, và tự động hóa kiểm thử trong môi trường Lab.

## Danh sách scripts dự kiến (Phát triển theo các Phase):
- `init_db.py`: Khởi tạo cấu trúc bảng SQLite và seed dữ liệu cấu hình ban đầu.
- `run_local_lab.sh`: Script tiện ích khởi động môi trường lab nhanh.
- `export_metrics.py`: Xuất kết quả đo đạc và báo cáo thực nghiệm sang định dạng CSV/JSON.
